# Python ve NumPy ile Sıfırdan Yapay Sinir Ağı

Bu proje, herhangi bir derin öğrenme framework'ü (PyTorch, TensorFlow, Keras vb.) kullanmadan, sadece Python ve NumPy kütüphanesi kullanılarak geliştirilmiş bir Yapay Sinir Ağı (Artificial Neural Network) uygulamasıdır. (sadece CIFAR10 veri setini indirmek icin torchvision kullanıldı)

Bu çalışmada [MNIST](https://www.kaggle.com/datasets/hojjatk/mnist-dataset) veri seti ve [CIFAR10](https://www.cs.toronto.edu/~kriz/cifar.html) kullanılarak model eğitilmiş ve test edilmiştir.
